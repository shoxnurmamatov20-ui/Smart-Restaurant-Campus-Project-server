# Codegen tools

Ichki kod generatorlar.

## Rejada

- **OpenAPI → TypeScript SDK** — `apps/api` dan OpenAPI spec olib, `packages/sdk/` ga TS client generatsiya
- **Modul scaffold** — yangi Laravel modul + uning Next.js sahifalarini birga yaratish (artisan + Next.js boilerplate)
- **i18n tarjima** — Yangi string qo'shilganda, AI orqali uz→ru, uz→en avtomatik tarjima taklif qilish
- **Migration → TypeScript types** — Laravel migration'dan Eloquent → TS types generate

> **Hozir bo'sh.** Tools kerak bo'lganda yozamiz.
